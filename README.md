# Vending Machine Pickup Line

Entry for the make.fun bounty **"One Line, One Minute: The Vending Machine Pickup Line Contest"** (`u-brisk-kestrel-93-one-line-one-minute-the-vending-376bbeee`).

## The line

> No exact change needed — just press B7. I've been humming in this hallway all day, but you walked by and now my coil won't stop spinning.

## Run

```sh
python3 main.py
```

This writes the single pickup line (one line, under 200 characters) to `/output/entry.txt`.

## Why this line works

The line speaks in the vending machine's own voice: "press B7" and "no exact change" set the scene instantly, then the machine's hum turns into a crush the moment someone walks by. The coil — the part that actually spins to drop the snack — becomes the punchline, a little machine heart that can't stop turning. It stays playful and flirty without breaking character, which is exactly what the brief asks for.
